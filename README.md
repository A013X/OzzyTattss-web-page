# OzzyTattss · Web de tatuador

Web de portafolio para el tatuador **OzzyTattss**: trabajos destacados, galería por estilos (color, realismo, black & grey, animales), vídeos y reservas.

🔗 **Web publicada:** https://ozzytatts-12a8d.web.app

## Qué incluye

- Diseño oscuro y elegante, adaptado a móvil.
- Galería de trabajos por categorías con miniaturas optimizadas.
- Sección de vídeos y botón de reserva.
- Publicada con **Firebase Hosting**.

## Tecnologías

HTML · CSS · JavaScript · Firebase Hosting

El diseño visual es mío; para parte del CSS me ayudé de IA.

> Las fotos de los tatuajes no están en este repositorio: se publican directamente en Firebase.
